# ACEM — AI Collaborative Engineering Methodology

A reusable engineering methodology governing how engineering projects are
executed using AI-assisted collaboration.

## Purpose

This repository **defines the engineering process**. It is the source of truth
for how engineering work is planned, reviewed, and approved when humans and AI
collaborate on engineering deliverables.

## Scope

- This repository defines the engineering process only.
- It is **technology independent**.
- It does **not** contain networking-specific, product-specific, or
  customer-specific content.

## Repository Structure

| Folder         | Purpose                                                        |
|----------------|----------------------------------------------------------------|
| `charter/`     | The ACEM charter — mission, principles, and authority.         |
| `methodology/` | The methodology itself — workflow and lifecycle.               |
| `roles/`       | Team roles and responsibilities.                               |
| `reviews/`     | The review process and review-package definition.              |
| `templates/`   | Reusable templates for charters, milestones, and reviews.      |
| `examples/`    | Illustrative, non-binding examples.                            |
| `changelog/`   | Record of changes to the methodology.                          |

## Status

Initial foundation. Placeholder documents are present for review and have not
